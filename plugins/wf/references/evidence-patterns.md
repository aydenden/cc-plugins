# 증거 검증 6종

생성되는 워크플로우의 각 단계는 "했다"고 말하는 대신 증거를 낸다. 다음 단계는 증거 없이 시작하지 않는다.

여섯 종류가 있고, 앞의 다섯은 **만들어진 것을 검사**하며 마지막 하나만 **만들어지지 않은 것**을 잡는다.

| 종류 | 막는 실패 | 판정 방법 |
|---|---|---|
| 존재 | 만들었다는데 없음 | 산출물 경로·ID를 실제로 열어본다 |
| 인용 | 없는 파일·줄·문서를 근거로 듦 | 인용 경로 실존 + 내용 대조 |
| 실행 | 안 돌리고 통과했다고 함 | exit code + 출력 캡처 경로 |
| 불변식 | 상태가 기대와 다름 | 관계·개수·순환을 질의 |
| 부정 | 안 찾아보고 "없다"고 함 | 실행한 검색 명령이 기록에 있는가 |
| **커버리지** | **검토 축이 통째로 빠짐** | **켜진 축 수 vs 산출물 항목 수** |

## 어느 단계에 무엇을 거나

일률적으로 여섯을 다 걸면 대부분이 형식적 통과 의례가 된다. 단계가 실제로 취약한 지점에만 건다.

| 단계 성격 | 걸어야 하는 것 |
|---|---|
| 조사·수집 | 인용, 부정 |
| 정의·설계 | **커버리지**, 인용 |
| 분해·적재 | 존재, 불변식 |
| 구현 | 실행 |
| 검증·테스트 | 실행, 존재 |
| 마감 | 실행, 불변식 |

인용과 부정은 특히 중요하다. 나머지는 안 하면 다음 단계에서 티가 나지만, **없는 근거를 지어내는 것과 안 찾아보고 없다고 하는 것은 끝까지 티가 안 난 채 흘러간다.**

## 스킬 본문이 아니라 hook으로 건다

스킬 본문의 "증거를 내라"는 권고이고 건너뛸 수 있다. hook은 harness가 실행하므로 건너뛸 수 없다.

- **차단이 맞는 것**: 인용(경로가 없으면 그 근거는 존재하지 않는다), 커버리지(축이 빠진 채 다음 단계로 가면 재작업)
- **경고로 충분한 것**: 부정(검색 명령 누락은 대개 게으름이지 오류가 아니다)

hook은 오탐이 나면 작업을 막는다. **명시적 우회 경로를 반드시 둔다.** 우회할 수 없는 검사는 결국 꺼진다.

## 우회에는 이유가 붙는다

우회 규칙의 정본은 이 절이다. 다른 문서는 여기를 가리킨다.

```bash
echo "style: 목업 미수령, ccp-k3d" >> .claude/wf-skip-checks    # <대상>: <왜>, <티켓>
```

- **이유 없는 마커는 우회가 아니다.** 빈 파일이면 검사가 그대로 돌고, 무엇을 적어야 하는지 알려준다. 검사가 꺼지는 지점이 아무것도 남기지 않으면 "통과했다"와 "껐다"가 같은 출력이 되고, 아래 「자기 보고 금지」가 바로 거기서 뚫린다.
- **기록은 스크립트가 한다.** 우회가 성립하면 이유를 출력하고 로그에 `<날짜> <검사>: <이유>` 한 줄을 남긴다. 사람이 옮겨 적게 두면 마커를 지울 때 이유도 같이 사라진다. 기록하지 못하면 우회하지 않는다.
- **로그는 워킹트리 밖에 산다.** `<git common dir>/wf-bypass.log` (`WF_BYPASS_LOG`로 변경). 프로젝트 폴더에 두면 커밋할 수 없는 저장소에서는 남길 곳이 없고, 워크트리는 작업이 끝나면 지워진다. git common dir는 모든 워크트리가 공유하고 커밋 대상이 아니다. 대신 clone을 넘어가지 않는다.
- **마커는 끝나면 지운다.** 마커는 "지금 우회 중"이라는 상태이고, 이력은 로그다.

같은 대상이 반복해서 우회되면 그 검사나 축, 또는 산출물 형태가 틀렸다는 신호다. `wf:retro`가 이 로그를 읽는다.

판정과 기록은 `bypass.sh` 하나가 하고, 세 검사는 그것을 **실행**한다. `source`하지 않는 이유는 실패 방향이다 — 불러들이는 방식은 파일이 빠졌을 때 검사가 exit 0으로 끝나지만, 실행하는 방식은 우회가 안 될 뿐 검사는 그대로 돈다. 생성되는 플러그인으로 복사되는 스크립트라 그 누락은 실제로 일어난다.

## 자기 보고 금지

생성되는 모든 스킬에 공통으로 박는다.

> "확인했다", "동작한다", "통과한다"는 옆에 명령 출력이 없으면 근거가 아니다. 관찰한 것과 추론한 것을 문장에서 분리한다.

## 스크립트

- `scripts/bypass.sh <검사 이름>` — 우회 판정과 기록. 세 검사가 부른다
- `scripts/check-citations.sh <파일...>` — 문서에서 경로 패턴을 뽑아 실존 검사
- `scripts/check-coverage.sh <축목록> <산출물>` — 켜진 축마다 행이 있는지(`UNADDRESSED`), 그 행에 출처·사유가 있는지(`INCOMPLETE`) 대조
- `scripts/check-negation.sh <파일...>` — "없음/없다/찾지 못" 주장 옆에 검색 명령이 있는지

생성기는 이 넷을 생성되는 플러그인의 `scripts/`로 복사하고, 필요한 단계의 hook에서 부르게 한다.
