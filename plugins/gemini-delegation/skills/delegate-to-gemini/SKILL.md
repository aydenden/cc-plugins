# Gemini CLI 분석 위임

대용량 분석 작업을 Gemini CLI에 위임하여 Claude 토큰을 절약한다.

## 트리거 조건

다음 상황에서 이 스킬을 사용한다:
- 500줄 이상의 파일 분석
- 3개 이상의 파일을 동시에 분석
- 로그 파일 분석 (에러, 성능, 보안)
- 프로젝트 아키텍처/구조 파악
- PR/코드 리뷰

## 역할 분담

| Gemini | Claude Code |
|--------|-------------|
| 코드 읽기/분석 | 설계 |
| 로그 패턴 분석 | 코드 작성 |
| 아키텍처 요약 | 실행/테스트 |
| PR 변경사항 리뷰 | 의사결정 |

## 사용 가능한 에이전트

분석 유형에 따라 적절한 에이전트를 선택한다:

1. **gemini-codebase**: 코드베이스 분석, 아키텍처 파악, 패턴 탐색
2. **gemini-logs**: 에러/성능/보안 로그 분석
3. **gemini-review**: PR 리뷰, 코드 변경사항 분석

## 워크플로우

1. 분석 대상과 목적 확인
2. 적절한 gemini-* 에이전트 호출
3. Gemini 분석 결과 수신
4. 결과 기반으로 Claude Code가 후속 작업 수행

## Gemini CLI 기본 사용법

```bash
# 파일 분석
gemini -p "분석 요청" @./파일경로 --output-format json

# 파이프 입력
cat 파일.log | gemini -p "분석 요청" --output-format json

# git diff 분석
git diff origin/main...HEAD | gemini -p "리뷰 요청" --output-format json
```

## 제한사항

- Gemini 비대화형 모드는 **읽기 전용** (파일 수정, 명령 실행 불가)
- 분석 결과를 바탕으로 한 실제 작업은 Claude Code가 수행
- 무료 티어: 분당 60요청, 일일 1000요청

## 토큰 절약 효과

| 작업 | 기존 | 위임 후 |
|------|------|---------|
| 10,000줄 코드 분석 | ~30K 토큰 | ~2K 토큰 |
| 대용량 로그 분석 | ~20K 토큰 | ~1K 토큰 |
| PR 리뷰 | ~10K 토큰 | ~1K 토큰 |
