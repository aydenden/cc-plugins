# 매수 진입 5단 체크리스트

## Workflow

### Step 1: 파라미터 확인

사용자로부터 확인:
- **종목코드** (필수)
- **진입가** (필수)
- **손절가** (필수)
- **총 투자금** (선택, 기본 10,000,000원)

### Step 2: 데이터 수집 (병렬)

```bash
# 일봉 OHLCV
node plugins/korean-trading/dist/kis/ohlcv.js {ticker}

# 투자자별 수급
node plugins/korean-trading/dist/kis/investor-trend.js {ticker}

# VKOSPI (시장 레짐)
node plugins/korean-trading/dist/krx/vkospi.js

# 재무비율
node plugins/korean-trading/dist/kis/financial-ratio.js {ticker}

# 신용잔고
node plugins/korean-trading/dist/kis/credit.js {ticker}

# 공매도
node plugins/korean-trading/dist/kis/short-sale.js {ticker}
```

### Step 3: 5단 체크

#### 체크 1: 시장 레짐
- [ ] VKOSPI < 25
- [ ] 시장 레짐이 "위기"가 아님
- 위기 시: **진입 금지** — 현금 보유 권장

#### 체크 2: 수급
- [ ] 외국인 최근 5일 순매수 (또는 매도 감소 추세)
- [ ] 기관 적대적 대량 매도 아님
- [ ] 공매도 비율 < 5%
- [ ] 신용잔고 비율 < 3%

#### 체크 3: 기술적
- [ ] 현재가가 20일 이동평균 위
- [ ] 거래량이 20일 평균 이상
- [ ] 명확한 지지선 존재 (손절가 근거)

#### 체크 4: 펀더멘탈
- [ ] PER이 업종 평균 이하 또는 합리적 수준
- [ ] ROE > 10% (또는 개선 추세)
- [ ] 최근 부정적 공시 없음

#### 체크 5: 포지션 사이징 (1% 룰)

```
총 투자금: {금액}원
리스크 허용: 1% = {금액 × 0.01}원
진입가: {진입가}원
손절가: {손절가}원
손절폭: {진입가 - 손절가}원 ({비율}%)
매수 수량: {리스크허용 / 손절폭}주
투입 금액: {수량 × 진입가}원 (총 투자금의 {비율}%)
```

### Step 4: 최종 판정

```
## 체크 결과
| 항목 | 결과 | 상세 |
|------|------|------|
| 시장 레짐 | ✅/❌ | VKOSPI {값} |
| 수급 | ✅/❌ | {요약} |
| 기술적 | ✅/❌ | {요약} |
| 펀더멘탈 | ✅/❌ | {요약} |
| 사이징 | ✅/❌ | {수량}주, {비중}% |

## 판정: ✅ 진입 가능 (4~5개) / ⚠️ 조건부 (3개) / ❌ 보류 (0~2개)
주의: {1~2줄}
```

## Position Sizing Reference

### 1% 룰
단일 종목 최대 손실 = 총 투자금의 1~2%

### 손절가 설정 기준
| 방법 | 설명 |
|------|------|
| ATR 기반 | 진입가 - (ATR × 2), 변동성 반영 |
| 지지선 하방 | 최근 지지선 아래 1~2% |
| 고정 비율 | 진입가 × (1 - 3~5%) |

### 레짐별 최대 비중
| 레짐 | 총 투자비중 | 종목당 비중 |
|------|-----------|-----------|
| 강세 (VKOSPI<15) | 80% | 20% |
| 보통 (15~25) | 60% | 15% |
| 약세 (25~35) | 30% | 10% |
| 위기 (>35) | 10% | 5% |
