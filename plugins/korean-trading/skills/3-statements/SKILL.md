# 재무3표 연결 분석 (3-Statement Model)

## Workflow

### Step 1: 데이터 수집 (병렬)
```bash
# 요약재무제표 (매출, 영업이익, 총자산, 총부채)
node plugins/korean-trading/dist/fsc/financial-statements.js {crno} {year} summary
# 재무상태표 (계정과목별)
node plugins/korean-trading/dist/fsc/financial-statements.js {crno} {year} bs
# 손익계산서 (계정과목별)
node plugins/korean-trading/dist/fsc/financial-statements.js {crno} {year} income
# DART 재무공시 (연간 사업보고서)
node plugins/korean-trading/dist/dart/disclosure.js {ticker} financial {year}
# 재무비율
node plugins/korean-trading/dist/kis/financial-ratio.js {ticker}
```

### Step 2: 손익계산서 (Income Statement) 분석
K-IFRS 기준 핵심 항목:
| 항목 | 설명 |
|------|------|
| 매출액 | 제품/서비스 매출 합계 |
| 매출원가 | 직접 생산비용 |
| 매출총이익 | 매출액 - 매출원가 |
| 판관비 | 판매비와관리비 |
| 영업이익 | 매출총이익 - 판관비 |
| 금융수익/비용 | 이자수익, 이자비용, 외환차손익 |
| 법인세비용 | |
| 당기순이익 | |

**핵심 마진 계산**:
- 매출총이익률 = 매출총이익 / 매출액
- 영업이익률 = 영업이익 / 매출액
- 순이익률 = 당기순이익 / 매출액

### Step 3: 재무상태표 (Balance Sheet) 분석
| 구분 | 핵심 항목 |
|------|----------|
| 유동자산 | 현금, 매출채권, 재고자산 |
| 비유동자산 | 유형자산, 무형자산, 투자자산 |
| 유동부채 | 매입채무, 단기차입금 |
| 비유동부채 | 장기차입금, 사채 |
| 자본 | 자본금, 이익잉여금 |

**핵심 비율**:
- 부채비율 = 총부채 / 자기자본
- 유동비율 = 유동자산 / 유동부채
- 순부채 = 총차입금 - 현금성자산

### Step 4: 현금흐름표 (Cash Flow) 추정
직접적인 CF 데이터가 없을 경우 IS + BS 변동으로 추정:
1. **영업활동 CF** ≈ 순이익 + 감가상각 - 운전자본 증가
   - 운전자본 변동 ≈ Δ매출채권 + Δ재고자산 - Δ매입채무
2. **투자활동 CF** ≈ -(Δ유형자산 + Δ무형자산 + 감가상각)
3. **재무활동 CF** ≈ Δ차입금 + Δ자본금 - 배당금

### Step 5: 3표 연결 검증
- BS 항목 연결: 기초 현금 + CF 합계 ≈ 기말 현금
- IS → BS: 당기순이익 → 이익잉여금 증가
- IS → CF: 순이익이 영업CF의 출발점

## Important Notes
- crno(법인등록번호)가 없으면 DART corp-codes에서 조회 필요
- FSC 재무제표 데이터가 없으면 DART 재무공시 + KIS financial-ratio로 대체
- 현금흐름표는 직접 데이터가 없어 추정임을 반드시 명시
- K-IFRS 연결재무제표 기준 (별도재무제표와 차이 있음)
- 매매 추천이 아님, 투자 판단은 사용자 책임
