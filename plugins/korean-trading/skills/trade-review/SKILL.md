# 매매 복기

## Workflow

### Step 1: 매매 정보 확인

사용자로부터 확인:
- **종목코드** (필수)
- **매수일** YYYYMMDD (필수)
- **매수가** (필수)
- **매도일** YYYYMMDD (필수)
- **매도가** (필수)
- **수량** (선택, 기본 1)

### Step 2: 데이터 수집

```bash
# 매매 기간 전후 일봉 (매수 1개월 전 ~ 매도 1주 후)
node plugins/korean-trading/dist/kis/ohlcv.js {ticker} D {매수일-30일} {매도일+7일}

# 투자자동향
node plugins/korean-trading/dist/kis/investor-trend.js {ticker}

# 재무비율 (매수 시점 기준)
node plugins/korean-trading/dist/kis/financial-ratio.js {ticker}

# 매수일 시장 레짐
node plugins/korean-trading/dist/krx/vkospi.js {매수일}
```

### Step 3: 분석

#### 매매 요약
```
종목: {종목명} ({ticker})
매수: {매수일} @ {매수가}원 × {수량}주
매도: {매도일} @ {매도가}원
손익: {금액}원 ({수익률}%)
보유기간: {일수}일
```

#### 진입 시점 분석
- 진입 시 시장 레짐 (VKOSPI 기준)
- 진입 시 수급 상황 (외국인/기관 동향)
- 진입 시 기술적 위치 (이동평균 대비)
- **진입 판단**: 적절 / 조기 진입 / 늦은 진입

#### 청산 시점 분석
- 청산 후 주가 흐름 (1주 후 가격)
- 놓친 수익 또는 추가 손실 방지 금액
- **청산 판단**: 적절 / 조기 청산 / 늦은 청산

### Step 4: 교훈 출력

```
## 매매 복기 결과

### 성과
- 손익: {금액}원 ({수익률}%)
- 진입 판단: {적절/조기/늦음}
- 청산 판단: {적절/조기/늦음}

### 잘한 점
1. {1~2개}

### 개선할 점
1. {1~2개}

### 다음 매매 적용사항
- {구체적 행동 1개}
```

## Important Notes

- 결과론적 판단(hindsight bias) 경계 — "당시 알 수 있었던 정보" 기준으로 평가
- 수익 매매도 복기 — "우연히 수익"인 경우 경고
