# 실적 분석

## Workflow

### Step 1: 데이터 수집 (병렬)
```bash
# 증권사 컨센서스 (목표가, 투자의견)
node plugins/korean-trading/dist/kis/consensus.js {ticker}
# 공시 데이터 (실적 공시)
node plugins/korean-trading/dist/dart/disclosure.js {ticker} financial {year}
# 재무비율 (PER/EPS 추이)
node plugins/korean-trading/dist/kis/financial-ratio.js {ticker}
# 주가 데이터 (실적 발표 전후 주가)
node plugins/korean-trading/dist/kis/ohlcv.js {ticker}
# 현재가 (최신 시세)
node plugins/korean-trading/dist/kis/current-price.js {ticker}
```

### Step 2: 실적 서프라이즈 판단
1. **컨센서스 확인**: consensus.ts에서 최근 목표가/투자의견 추이
2. **실제 실적 확인**: DART 재무공시에서 매출/영업이익/순이익
3. **서프라이즈 계산**:
   - 매출 서프라이즈 = (실제 - 컨센서스) / 컨센서스 × 100%
   - 영업이익 서프라이즈 = (실제 - 컨센서스) / 컨센서스 × 100%
   - 컨센서스 직접 수치 없으면: 전년 동기 대비 성장률로 판단

### Step 3: 분기별 실적 추이 분석
1. **YoY (전년 동기 대비)**: 매출/영업이익/순이익 성장률
2. **QoQ (전분기 대비)**: 계절성 파악
3. **마진 추이**: 영업이익률, 순이익률 변화

### Step 4: 주가 반응 분석
1. **실적 발표 전**: 발표 20일 전~발표일 수익률
2. **실적 발표 후**: 발표일~발표 5일 후 수익률
3. **패턴 판단**:
   - 선반영(Priced In): 발표 전 상승 + 발표 후 하락
   - 서프라이즈 랠리: 발표 후 +3% 이상 상승
   - 어닝 쇼크: 발표 후 -3% 이상 하락
   - 무반응: 발표 전후 ±1% 이내

## Important Notes
- DART 재무공시는 분기별로 reprt_code가 다름: 11013(1분기), 11012(반기), 11014(3분기), 11011(사업보고서)
- 컨센서스 수치가 없으면 전년 동기 대비 성장률로 서프라이즈 판단
- 실적 발표일이 불명확하면 DART 공시일 기준
- 매매 추천이 아님, 투자 판단은 사용자 책임
