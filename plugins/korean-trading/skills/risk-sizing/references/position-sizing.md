# 포지션 사이징 계산 레퍼런스

## 1% 룰 상세

```
매수 수량 = (총 투자금 × 리스크%) / (진입가 - 손절가)
```

### 계산 예시

```
총 투자금: 10,000,000원
리스크 허용: 1% = 100,000원
진입가: 70,000원
손절가: 67,000원 (약 -4.3%)
손절폭: 3,000원

매수 수량 = 100,000 / 3,000 = 33주
투입 금액 = 33 × 70,000 = 2,310,000원 (총 투자금의 23.1%)
```

## 켈리 공식

```
bet_fraction = (승률 × 평균수익 - (1 - 승률) × 평균손실) / 평균수익
```

실전 적용: Half Kelly (켈리의 50%) 또는 Quarter Kelly 권장.

## 손절가 설정 방법

| 방법 | 공식 | 장점 | 단점 |
|------|------|------|------|
| ATR 기반 | 진입가 - ATR×2 | 변동성 반영 | ATR 계산 필요 |
| 지지선 하방 | 지지선 - 1~2% | 기술적 근거 | 주관적 |
| 고정 비율 | 진입가 × 0.95~0.97 | 단순 | 변동성 미반영 |
| 전일 저가 | 전일저가 - 1% | 단타 적합 | 스윙에 부적합 |

## 익절 전략

### R 배수
- 1R = 손절폭과 동일한 수익폭
- 단타: 1.5~2R 목표
- 스윙: 2~3R 목표

### 분할 익절
1. 1R 도달: 50% 익절
2. 나머지: 트레일링 스탑 (최고가 대비 -2~3%)

## 자금 관리 규칙

1. 동시 보유 종목: 최대 3~5종목
2. 섹터 집중: 동일 섹터 최대 2종목
3. 일일 최대 손실: 총 투자금의 3% → 당일 거래 중단
4. 연속 손절: 3연속 시 크기 50% 축소, 5연속 시 1일 휴식
5. 수익 보호: 당일 +2% 이상 후 반토막 → 당일 종료
