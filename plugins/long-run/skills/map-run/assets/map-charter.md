# 맵 헌장 템플릿 — bd epic 본문

이 템플릿을 채워 `bd create -t epic` 의 `--description-file` 로 넣는다. 맵 본문은 세션이 갈려도 남는
유일한 계약이라, 세션마다 다시 합의해야 하는 것은 전부 여기 있어야 한다.

`{중괄호}` 는 채우고, 「운영 규약」 절은 **문장째로 그대로** 옮긴다 — 그 절을 요약하면 새 세션이
해석 여지를 갖고, 해석 여지가 곧 「다음으로 갈까요?」 로 멈추는 자리가 된다.

---

```markdown
## Destination

{끝났을 때 세상이 어떤 상태인지 3~6줄. 할 일 목록이 아니라 도착지다.
"무엇을 만든다" 가 아니라 "무엇이 가능해진다" 로 쓴다.}

## 완료 조건

{관측 가능한 문장으로. 각 줄이 참/거짓으로 판정되어야 한다.}

- {예: `node tools/x/y.mjs` 한 번으로 산출물이 선다}
- {예: 전 스위트가 초록이고 게이트 3층을 통과한다}

## 확정된 결정

{사용자가 이미 고른 것. 고른 이유까지 적는다 — 이유가 없으면 다음 세션이 다시 고른다.
선행 `/wayfinder` 맵이 있으면 그 «Decisions so far» 가 그대로 여기로 온다 — 링크만 두지 말고
한 줄 요지를 옮긴다. 다음 세션이 링크를 타지 않아도 판단할 수 있어야 한다.}

- {결정} — {근거}

## 아직 규정 못 한 것

{올 줄은 알지만 지금 티켓으로 못 쪼개는 것. **비어 있어도 절은 남긴다.**

판정 기준은 «지금 답할 수 있나» 가 아니라 **«지금 질문을 정확히 말할 수 있나»** 다.
말할 수 있으면 — 막혀 있어도 — 티켓이다. 못 하면 여기다.

이 절이 있는 이유: 프론티어가 비었을 때 «다 했다» 와 «아직 못 적었다» 를 가드는 구분하지 못한다.
여기가 비어 있지 않으면 프론티어가 비어도 끝난 것이 아니다.

티켓이 풀려 여기 한 덩이를 말할 수 있게 되면 **그 자리에서 티켓으로 졸업시키고 여기서 지운다** —
두 곳에 남기면 같은 일을 두 번 센다.}

- {의심되는 질문 / 나중에 다시 볼 자리}

## 범위 밖

{목적지 밖으로 **의식적으로** 쫓아낸 것. 안개가 아니라 경계다 — 졸업하지 않는다.
이미 만든 티켓이 목적지 밖이었다고 드러나면 그 티켓을 **닫고** 여기 한 줄 남긴다(닫힌 티켓만이
프론티어에서 확실히 빠진다). 「확정된 결정」에는 넣지 않는다 — 그건 실제로 걸은 길의 기록이다.}

- {무엇} — {왜 이 맵의 밖인가}

## 이미 실패한 접근 — 다시 파지 말 것

{비어 있어도 절은 남긴다. 맵이 굴러가며 여기가 자산이 된다.}

- 🚨 {무엇을 시도했고 무엇에서 죽었는가. 증상과 잘못 읽히는 신호까지}

## 운영 규약 — 그대로 옮긴다

- **묻지 않고 완료조건까지 간다.** 한 번에 티켓 하나(`bd ready` → `--claim`) → 작업 → `bd close --reason`.
  멈춰도 되는 자리는 넷뿐이다: ① 프론티어가 비었다 ② 컨텍스트 50% 초과(그때는
  `/long-run:session-handoff`) ③ 승인이 필요한 바깥 쓰기(이슈 트래커·문서·push·외부 시스템)
  ④ **목적지를 바꾸는 갈림길**(아래). 그 넷이 아니면 보고는 작업 사이가 아니라 세션 끝에 한 번 한다
- **갈림길과 국소 선택을 가른다 — 묻는 것은 갈림길뿐이다.**
  - **갈림길(A/B): 묻는다.** Destination·완료 조건을 고쳐 쓰게 되거나, 되돌리기 비싼 것을 확정하는
    선택(외부 계약, 데이터 형태, 공개 인터페이스, 이미 확정된 결정을 뒤집는 것). 한 줄로 묻고,
    답을 「확정된 결정」에 근거까지 적는다
  - **국소 선택(A.1/A.2): 스스로 결정한다.** 어느 쪽을 골라도 완료 조건의 참/거짓이 같은 선택. 묻지
    않고 고르고, **왜 골랐는지를 `bd close --reason` 에 남긴다.** 다음 세션이 다시 고르게 만드는 것이
    이 자리의 실패다. 그 선택이 뒤 티켓의 전제가 되면 「확정된 결정」에도 한 줄 올린다
  - 판정이 서지 않으면 **그것이 갈림길이라는 신호다** — 완료 조건으로 판정할 수 없다는 뜻이므로 묻는다
  - 갈림길 하나가 결정을 줄줄이 끌고 오면 그건 안개다. 「아직 규정 못 한 것」에 적고, 규모가 크면
    사용자에게 `/wayfinder` 로 돌아갈 것을 제안한다 — 실행 맵 안에서 결정 맵을 굴리지 않는다
- **작업 중 새 미지수는 현재 티켓을 넓히지 않고** `bd create --deps discovered-from:<현재>` 로 형제를 만든다
- 🚨 **측정 티켓이 낸 크기·경계는 그 자리에서 후속 구현 티켓으로 만든다.** 만들지 않으면 프론티어가
  인위적으로 비고, 그것을 「다 했다」로 읽게 된다. 내가 만든 티켓을 내 판단으로 보류해 프론티어를
  비우는 것도 같은 고장이다
- **크기를 모르는 채로 구현 티켓을 쪼개지 않는다** — 첫 티켓은 측정이다
- **팬아웃 금지**(사용자 전역 규약). 메인 직접 → 부족하면 서브에이전트 하나
- **인계 문서 §0 은 이어진다** — 이전 인계의 §0 을 그대로 가져와 이번에 추가된 것만 덧붙인다

## 증거

{산출물·인계 문서가 쌓이는 절대경로. 선행 재료가 있으면 그 경로도}

## 선행 맵

{있으면 무엇을 물려받는지. 접힌 실행 맵이면 그 close reason 이 출발점이라고 적는다.
선행 `/wayfinder` 맵이면 그 맵의 링크와, 어느 절이 어디로 왔는지 한 줄:
Decisions so far → 확정된 결정 / Not yet specified → 아직 규정 못 한 것 · 초기 티켓 /
Out of scope → 범위 밖}
```
