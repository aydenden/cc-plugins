"$ARGUMENTS"를 조사해서 LLM Wiki 볼트에 적재해줘.

## 볼트 경로

```bash
WIKI="${WIKI_PATH:-$OBSIDIAN_VAULT_PATH}"
```

`WIKI`가 미설정이면 사용자에게 안내하고 중단.

## 경계 — 이 커맨드는 소스를 확보하는 데까지다

조사는 서브에이전트에 라운드마다 하나씩 위임하고, **적재는 `wiki-schema` 스킬이 소유한다.** 절차가 두 벌이 되면 한쪽만 낡는다(그 비용의 실물이 구 `research-agent`였다).

## 1. 오리엔테이션 (wiki-schema 규칙 1)

이 세션에서 아직 안 했다면: `SCHEMA.md` Read → 루트 `index.md` 전체 Read → `tail -40 log.md`.

## 2. 기존 페이지 먼저 확인 (wiki-schema 규칙 3)

Grep 전수검색은 0.02초다. 조사를 위임하기 **전에** 확인해서 이미 있는 것을 다시 조사하지 않는다. 확장 규칙은 `${CLAUDE_PLUGIN_ROOT}/skills/wiki-schema/references/search-expansion.md`.

- 관련 페이지 있음 → 상위 1~3개 Read → 3-3 기준으로 얕은 곳이 없으면 요약 + 경로 보고 후 **종료**. 얕은 곳이 있거나 갱신이 필요하면 3단계로.
- 없음 → 3단계.

## 3. 조사 루프

얕은 지점이 없어질 때까지 라운드를 반복한다. 한 라운드로 끝내면 빠진 것을 아무도 모른 채 페이지가 된다.

- **동시에 하나만.** 라운드마다 Task 도구로 `general-purpose` 서브에이전트를 **새로 하나** 띄운다. 병렬 팬아웃하지 않는다 — 조사 원문이 메인 컨텍스트를 밀어내는 것을 막는 게 위임의 목적이지, 속도가 아니다. 이전 라운드 에이전트를 이어 쓰지 않는다(컨텍스트만 찬다).
- **비용.** 라운드 수만큼 서브에이전트 비용이 든다. 사용자가 이 커맨드를 직접 호출한 것을 그 비용에 대한 동의로 본다.
- **판정은 메인이 한다.** 조사한 쪽의 자기 판정은 관대하다.
- **적재는 루프가 끝난 뒤 한 번만.** `log.md`에 쓰는 순간 훅이 커밋·푸시까지 돌린다.

### 3-1. 질문 세우기

조사 전에 메인이 쓴다.

- **범위:** 이 조사가 답할 것을 한 문장으로. 뒤에서 범위 밖 질문을 거르는 기준이다.
- **하위 질문 5~8개:** 답하면 주제를 이해했다고 할 수 있는 질문들. 2단계에서 찾은 기존 페이지를 갱신하는 경우, 그 페이지가 답하지 못한 것을 질문으로 삼는다.

### 3-2. 라운드 위임

프롬프트(그대로 전달, `$ARGUMENTS`·`$WIKI`와 `{…}` 자리는 실제 값으로 치환):

````
주제: $ARGUMENTS
볼트: $WIKI
범위: {범위 한 문장}

조사할 질문: (이번 라운드에 열려 있는 것만)
- Q1. {질문} — 이전 약점: {판정과 이유. 1라운드면 생략}

이미 확보한 raw: {경로 목록. 없으면 "없음"} — 다시 저장하지 말고 필요하면 Read한다.
이미 시도한 질의·채널: {목록. 없으면 "없음"} — 같은 검색을 반복하지 말고 다른 질의·채널을 쓴다.
이미 제외된 채널: {목록. 없으면 "없음"} — 다시 탐지하지 않는다.

너는 조사만 한다. 위키 페이지를 쓰지 마라 — 적재는 메인 세션이 한다.

1. `${CLAUDE_PLUGIN_ROOT}/docs/research-channels.md`를 Read하고 그 레지스트리대로
   질의 성격에 맞는 채널만 고른다. 필요한 선택 채널만 1회 탐지하고, 실패하면 즉시 축퇴한다.
2. 조사 원칙: 공식 문서·1차 자료 우선, 최신 우선, 각 사실에 출처 URL과 발행일.
   추측 금지 — 출처 없는 사실은 보고하지 않는다.
2-1. **WebFetch가 403·빈 본문·"Just a moment…"로 막히면 포기하기 전에 브라우저 사다리를 한 계단
   올라간다.** 절차는 `${CLAUDE_PLUGIN_ROOT}/docs/browser-fallback.md`를 Read해 그대로 따른다.
   한 번에 한 계단이고, 세 계단이 다 막히면 그 URL을 조사 제외 채널에 남긴다.
3. **원문을 반드시 `raw/`에 파일로 남긴다.** 요약만으로 페이지를 쓰면 품질이 떨어지므로
   메인이 필요한 원문을 골라 읽을 수 있어야 한다. 저장 위치·frontmatter(`source_url`/
   `ingested`/`sha256`)·재ingest 감지는 `${CLAUDE_PLUGIN_ROOT}/skills/wiki-schema/SKILL.md`
   규칙 2를 Read해 그대로 따른다. 웹 문서는 `raw/articles/`, 논문은 `raw/papers/`.
   `raw/`의 기존 파일은 수정하지 않는다(추가만).
   **전문을 직접 읽었고 답의 근거로 쓴 원문만 남긴다.** 쓰지 않은 원문은 흡수되지 않은 대기열로 쌓인다.
   파일로 남길 수 없는 근거(초록만 공개된 논문 등)는 답의 약점에 그 사실을 적는다.
4. 볼트의 다른 어떤 파일도 만들거나 고치지 않는다(`index.md`·`log.md`·위키 디렉토리 포함).
5. 답에는 수치·조건·작동 원리·반례 중 확인한 것을 적는다. 못 찾았으면 지어내지 말고 못 찾았다고 적는다.

반환은 아래 형식으로 60줄 이내. **본문·원문·긴 인용을 반환에 넣지 마라** — 메인이 raw 파일을
직접 Read한다.
````

### 3-3. 판정

반환을 받으면 질문마다 아래를 본다. 하나라도 해당하면 그 질문은 **열림**이다.

| 판정 | 기준 |
|---|---|
| 미답 | 답을 찾지 못했다 |
| 단일 출처 | 근거가 1개뿐이다 |
| 2차 자료만 | 1차 자료 없이 블로그·요약글뿐이다 |
| 원문 미확인 | 스니펫·초록만 봤다. context7·`gh`처럼 파일로 남기지 않는 채널을 직접 조회한 것은 원문으로 친다 |
| 일반론 | 수치·조건·작동 원리·반례가 없다 |
| 충돌 | 출처끼리 다른데 정리되지 않았다 |
| 낡음 | 빠르게 변하는 주제인데 발행일이 오래됐다 |

- 원문 하나로 답이 확정되는 질문(공식 문서의 사양·버전 등)은 단일 출처로 열지 않는다.
- 근거로 적힌 raw 파일이 실제로 있는지 Glob으로 확인한다. 없으면 원문 미확인이다. 이 확인은 존재만 본다 — 내용 대조는 4단계에서 한다.
- 새로 발견한 질문은 범위 안이면 추가하고, 범위 밖이면 추가하지 않고 보고에만 남긴다.

### 3-4. 종료

아래 중 하나면 루프를 끝내고 4단계로 간다. 그 외에는 열린 질문만 담아 3-2로 돌아간다.

1. **열린 질문이 없다.**
2. **상한:** 5라운드를 마쳤다. 남은 질문은 `미해결`로 닫는다.

어떤 질문이 2라운드 연속 진전(새 출처나 새 사실)이 없으면 그 질문만 `도달 불가`로 닫고 나머지는 계속한다. 끝낼 수 없는 판정이 되지 않게 하는 안전장치이므로, 이렇게 닫은 질문은 충분한 것으로 치지 않고 보고한다.

## 4. 적재 (wiki-schema 규칙 3~9)

루프가 끝나면:

1. 질문별 답을 보고 페이지의 근거로 쓸 raw 파일만 Read한다. 전부 읽지 않는다. 답과 raw가 어긋나면 raw를 따르고 보고에 적는다 — 서브에이전트의 답은 요약일 뿐이다.
2. 규칙 3~9를 순서대로 수행한다 — 기존 페이지 확인 → 페이지 작성·갱신(type↔디렉토리, frontmatter 8필드, summary, sources, confidence, 태그) → 교차참조 → `log.md` append → 훅이 돌린 lint 결과 처리 → 보고.
3. `sources:`에는 페이지 내용의 근거가 된 `raw/…` 경로를 쓰고, raw가 없는 사실만 URL을 직접 적는다. 읽지 않은 raw를 흡수 처리하려고 `sources:`에 넣지 않는다 — 출처 표기가 거짓이 된다. 남은 raw는 `raw-unabsorbed` 백로그로 드러나게 두고 보고한다.
4. `도달 불가`·`미해결` 질문은 페이지 본문에 열린 질문으로 적는다. 답이 있는 것처럼 쓰지 않는다.
5. `index.md`는 손대지 않는다(lint가 재생성).

## 5. 보고

wiki-schema 규칙 9의 보고에 다음을 한 줄씩 반드시 옮긴다. 축퇴와 공백을 조용히 삼키면 나중에 이 페이지의 커버리지를 판단할 수 없다.

- **라운드 수와 종료 사유**
- **`도달 불가`·`미해결` 질문**과 범위 밖으로 뺀 질문
- **조사 제외 채널** (모든 라운드 합산)
