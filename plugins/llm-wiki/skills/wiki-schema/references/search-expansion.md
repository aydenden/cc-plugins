# 볼트 검색: 쿼리 확장과 index 폴백

볼트 검색의 SSoT. `/recall`, `/capture`, 적재 절차(SKILL.md 규칙 3)가 모두 이 규칙을 따른다.

## 1단계: Grep 전수검색 (1차 경로)

검색 엔진은 **CC 내장 Grep**이다. 볼트 마크다운 총량 8.5MB, 전수검색 실측 0.02초 — 인덱스도 사전 준비도 없다.

대상은 `$WIKI`의 `entities/` `concepts/` `comparisons/` `queries/` `summaries/`. `raw/`는 원문 더미라 기본 제외하고, 위키 계층에서 아무것도 안 나올 때만 마지막으로 훑는다.

```
Grep(pattern: "<확장된 정규식>", path: "$WIKI",
     glob: "{entities,concepts,comparisons,queries,summaries}/**/*.md",
     output_mode: "content", -i: true, -C: 2, head_limit: 60)
```

## 쿼리 확장 (필수)

형태소 분석기가 없으므로 **에이전트가 직접 표기 변형을 넓힌다.** 원문 질의 한 벌만 던지고 "없음"으로 끝내지 말 것 — 한국어 볼트에서 미적중의 대부분은 부재가 아니라 표기 불일치다.

이 절은 장식이 아니다. 실측(ccp-8zb, 118문항)에서 질의 토큰에 조사가 붙는 것만으로 MRR이
**0.955 → 0.601**, r@1이 0.949 → 0.475로 반토막 났고, **아래 조사·어미 절단만 적용해도
0.955로 완전히 복구**됐다. 확장을 건너뛴 호출이 곧 검색 실패다.

한 번의 Grep에 정규식 교대(`가상\s*스레드|virtual\s*thread|버추얼`)로 묶어 넣는다:

- **띄어쓰기 변형** — `\s*`로 흡수 (`가상 스레드` / `가상스레드`)
- **조사·어미 절단** — 어간만 남긴다 (`카프카의` → `카프카`, `설계했다` → `설계`)
- **한↔영 병기** — 한국어 용어는 영어 원어를, 영어 용어는 국문 음차를 함께 (`관측성|observability|옵저버빌리티`)
- **약어 ↔ 전개형** — `LLM|large language model`, `k8s|kubernetes`
- **하이픈·대소문자** — `-`는 `[-\s]?`로, 검색은 항상 `-i`

여러 개념이 섞인 질의는 개념별로 Grep을 나눠 돌리고 교집합 페이지를 우선한다.

## 2단계: index 폴백 (미적중일 때만)

1단계가 비었거나, 볼트가 이 주제를 어떤 어휘로 부르는지 자체가 불확실하면:

1. 루트 `index.md` **전체 Read** — 주제군 지도다. 어느 카테고리에 속하는지, 볼트가 쓰는 용어가 무엇인지 파악한다. (오리엔테이션에서 이미 읽었다면 다시 읽지 않는다.)
2. 해당 디렉토리의 `index.md`(전수 카탈로그, lint 자동 생성)로 하강해 제목·요약을 훑는다.
3. 거기서 얻은 어휘로 1단계 Grep을 다시 돌린다.

index는 **폴백이자 쿼리 어휘 공급원**이지 1차 경로가 아니다. 등재율이 완전하지 않을 수 있으므로 index에 없다는 이유로 페이지가 없다고 결론내지 않는다.

## 제목·파일명 우선 (순위 보정)

**본문 적중 라인 수는 관련도가 아니다.** 실측(ccp-8zb)에서 실패한 질의는 전부 부재가 아니라
순위 밀림이었고, 패턴이 하나였다 — 짧고 정의적인 **엔티티 허브 페이지가 그 엔티티를 길게
언급하는 페이지에 밀린다**(`entities/opencode.md`가 35위). 1단계는 `head_limit: 60`줄이라
밀린 페이지는 눈에 들어오지도 않는다. 그래서 1단계 결과를 볼 때:

- 질의어가 **파일명 또는 H1에 있는 페이지를 먼저** 본다.
- 고유명사(제품·도구·인물)가 질의에 있으면 `glob: "entities/**/*.md"`로 **한 번 더** 돌린다.
- `index.md` 적중은 후보가 아니라 어휘 공급원으로만 쓴다(전수 카탈로그라 무엇에나 얕게 걸린다).

## 3단계: 후보 선별 · 본문 확장

- Grep 컨텍스트로 관련성을 판단해 **상위 1~5개만** 선별한다.
- 선별한 파일을 **Read**하여 전체 본문 확인.
- 각 페이지의 `[[wikilink]]`를 따라 1-hop 이웃도 필요 시 확인.
- 적중 파일을 무턱대고 전부 Read하지 말 것 — 스니펫으로 좁힌 뒤 최소한만 확장(토큰 절약).

## "없음"의 기준

쿼리 확장과 index 폴백까지 마친 뒤에만 "없음"이라고 말한다. 그 뒤에도 비었으면 "볼트에 관련 페이지 없음"으로 짧게 알리고, 시도한 확장 표기를 한 줄로 덧붙인다.
