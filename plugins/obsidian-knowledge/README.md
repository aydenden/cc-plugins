# obsidian-knowledge

Obsidian 볼트 기반 지식 관리 워크플로우 — 포착(capture), 회수(recall), 조사(research)

## 커맨드

| 커맨드 | 설명 |
|--------|------|
| `/obsidian-knowledge:capture <노트 제목 또는 URL>` | 대화 지식 또는 웹 페이지를 Obsidian 볼트에 저장 |
| `/obsidian-knowledge:recall <검색 키워드>` | Obsidian 볼트에서 관련 노트를 검색하여 컨텍스트에 주입 |
| `/obsidian-knowledge:research <조사할 주제>` | 주제를 조사하여 Obsidian 볼트에 리서치 노트를 작성 |

## 에이전트

| 에이전트 | 설명 |
|----------|------|
| research-agent | Obsidian 볼트 검색 → 외부 조사 → 문서 작성까지 자율 수행하는 리서치 에이전트 |
