Obsidian 볼트에서 "$ARGUMENTS"와 관련된 지식을 찾아 현재 작업 컨텍스트에 주입해줘.

## 환경변수

볼트 경로: `OBSIDIAN_VAULT_PATH` 환경변수에서 가져온다. 설정되지 않았으면 사용자에게 안내하고 중단.

## 검색 절차 (2단계, 반드시 순서대로)

### 1단계: Frontmatter 스캔 (토큰 절약)

3가지를 **병렬**로 수행:

1. **frontmatter summary 검색** — Grep으로 `summary:` 필드에서 키워드 매칭
2. **frontmatter tags 검색** — Grep으로 `tags:` 필드에서 키워드 매칭
3. **파일명/경로 검색** — Glob으로 키워드가 포함된 `.md` 파일 탐색

검색 경로: `$OBSIDIAN_VAULT_PATH/**/*.md`

결과에서 관련성 높은 후보 1~5개를 선별한다.

### 2단계: 후보 노트 본문 읽기

선별한 후보 각각에 대해 **병렬** 수행:
- Read로 본문 확인
- Grep으로 `[[노트명]]` 형태의 백링크를 가진 다른 노트도 탐색

## 결과 제공

```
## 볼트 검색 결과: $ARGUMENTS

### 발견된 노트
1. **노트명** — 핵심 요약 1~2줄
2. **노트명** — 핵심 요약 1~2줄

### 관련 인사이트
- 현재 작업에 적용 가능한 패턴/결정/교훈 요약

### 연결된 노트 (백링크)
- [[관련노트]] — 관련 이유
```

## 주의사항

- 전체 노트를 그대로 출력하지 말 것 (토큰 낭비). 핵심만 요약.
- frontmatter가 없는 노트는 파일명으로 판단.
- 검색 결과가 없으면 "볼트에 관련 노트 없음"으로 짧게 알리고 끝낸다.
- 현재 작업 맥락과 연결해서 어떻게 활용할 수 있는지 제안한다.
