argument-hint: <검색 키워드>
---

Obsidian 볼트에서 "$ARGUMENTS"와 관련된 지식을 찾아 현재 작업 컨텍스트에 주입해줘.

## 검색 절차 (2단계)

### 1단계: 키워드 검색

```bash
obsidian search query="$ARGUMENTS" limit=10
```

결과에서 관련성 높은 후보 1~5개를 선별한다.

### 2단계: 후보 노트 심화 탐색

선별한 후보 각각에 대해 **병렬** 수행:

```bash
# 본문 읽기
obsidian read file="노트명"

# 백링크 탐색 — 이 노트를 참조하는 다른 노트도 확인
obsidian backlinks file="노트명"
```

## 결과 제공

검색 결과를 다음 형식으로 요약한다:

```
## 볼트 검색 결과: $ARGUMENTS

### 발견된 노트
1. **노트명** — 핵심 요약 1~2줄
2. **노트명** — 핵심 요약 1~2줄

### 관련 인사이트
- 현재 작업에 적용 가능한 패턴/결정/교훈 요약

### 연결된 노트 (백링크)
- [[관련노트]] — 관련 이유
```

## 주의사항

- 전체 노트를 그대로 출력하지 말 것 (토큰 낭비). 핵심만 요약.
- 검색 결과가 없으면 "볼트에 관련 노트 없음"으로 짧게 알리고 끝낸다.
- 현재 작업 맥락과 연결해서 어떻게 활용할 수 있는지 제안한다.
